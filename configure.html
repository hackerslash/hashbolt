02

Hashbolt's index grows from its users' libraries, so sharing is a condition of using it.

  • While I use Hashbolt, it reads my TorBox torrents and web downloads, at most once every 6 hours.
  • For each finished item it saves the info hash, name, size and file names. For web downloads it also saves the original download link, which can give access to the file itself (for example Google Drive or gofile links).
  • This data goes into a shared database and an index on GitHub that may be made public for anyone to download. It is not deleted when I stop using Hashbolt.
  • My API key, email, account ID and IP address are never saved with it, so entries are not linked to me.
  • I can stop sharing at any time by uninstalling the addon.
